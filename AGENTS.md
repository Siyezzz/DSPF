# Project Directory Conventions

- `data/raw/`: source data; keep original inputs unchanged.
- `data/processed/`: cleaned or transformed datasets.
- `docs/plans/`: project plans.
- `docs/notes/`: working notes and documentation.
- `src/`: source code and analysis scripts.
- `output/figures/`: generated figures.
- `output/tables/`: generated tables.
- `report/`: report materials.
- `slides/`: presentation materials.
- `tests/`: automated tests.
- `temp/`: disposable temporary files; do not commit generated contents.
- `.state/`: local workflow state; do not commit generated contents.
- `.logs/`: local logs; do not commit generated contents.
